# Arthur Pontes

**Full stack developer · TypeScript, Node.js, React, PostgreSQL** · Taubaté, SP, Brazil

I build web applications end to end, and most of my time goes into the backend: REST APIs with
Fastify and Prisma, relational modeling in PostgreSQL, validation with Zod, JWT auth and
automated tests. On the frontend I work with React, Vite and Tailwind.

Several of my projects started as something that only half worked, like an old static site or a
PHP college assignment, and ended up as complete applications with a real API, a database and
a test suite behind them.

### Now

- Building a scheduling API with background jobs for reminders (Fastify, Prisma, pg-boss)
- Learning CI with GitHub Actions and containerized development
